# On-device LLM model

Place the MediaPipe LiteRT model file here before building:

`gemma3-1b-it-int4.task`

Full path:

`BilingualReader/src/main/assets/llm/gemma3-1b-it-int4.task`

The `.task` file is gitignored (~555 MB). Download it locally from the LiteRT community Gemma 3 1B IT INT4 release and drop it into this folder.
